# Derived data

Processed, EEZ-averaged monthly time series (2005–2025, 252 months) generated by
the scripts. These are not the raw source products (see the top-level README).
Missing values: Chl-a is missing in 5 months with no valid MODIS retrievals
(coded -999 in the Earth Engine export, NaN elsewhere).

| File | Contents | Script |
|------|----------|--------|
| `BoB_EEZ_SST_Chl_monthly_2005_2025.csv` | SST, MODIS Chl-a (log-mean, median, valid-pixel %) | 00 (Earth Engine) |
| `BoB_EEZ_SSS_monthly_2005_2025.csv` | SSS EEZ mean (GLORYS12V1) | 01 |
| `BoB_EEZ_master_with_anomalies.csv` | all three variables + deseasonalised anomalies | 02 |
| `BoB_EEZ_master_with_indices.csv` | master + IOD (DMI) and ENSO (Niño 3.4) | 05 |
| `climate_indices_2005_2025.csv` | DMI and Niño 3.4, 2005–2025 | 05 |
| `BoB_EEZ_GlobColour_monthly_2005_2025.csv` | Copernicus-GlobColour Chl-a EEZ mean | 06 |
| `BoB_EEZ_chl_MODIS_vs_GlobColour.csv` | MODIS vs GlobColour monthly Chl-a | 06 |
